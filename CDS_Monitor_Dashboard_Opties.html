Aanbevolen voor: bestuurlijke & politieke rapportage

Filtermogelijkheden
  • Per zorgverzekeraar (CZ / VGZ / Menzis / Zilveren Kruis)
  • Per ROAZ-regio
  • Per dataplatform (HinQ, KPN HEX, VIPPLive, Boards…)
Kleurcodering
  • 🟢 Groen — Implementatie / Actief

  • 🔴 Rood — Niet gestart
  • ⚪ Grijs — Onbekend

  • Tableau + GeoJSON
  • Plotly Dash (Python)

Multidimensionele RAG-heatmap

Aanbevolen voor: intern programmamanagement

Matrix-weergave: 31 regio's (rijen) × 4 domeinen + KPI's (kolommen). Elke cel toont status én een volledigheidspercentage. Klik op een cel voor drilldown.

Extra's
  • Automatisch berekend "Datavolledigheid %" per regio
  • Sorteerbaar op slechtst-scorende regio's bovenaan
  • Exporteerbaar naar PDF/Excel voor overleg
  • Kleurcodering direct zichtbaar zonder toelichting
Technische opties
  • Power BI Matrix visual
  • Google Looker Studio
  • Streamlit (Python)
Meerwaarde

Directe prioritering — in één tabel zichtbaar welke regio's de meeste aandacht nodig hebben.

Gelaagd KPI Scorecard Dashboard

Aanbevolen voor: stuurgroeprapportage

Drie lagen in één dashboard: KPI-tiles bovenaan, domein-tabs en een regio-selectiepanel.

Drie lagen
  • Laag 1: KPI-tiles — % gestart, # koplopers, % contactpersonen bekend
  • Laag 2: Domein-tabs — Datasamenwerking / ICM / Zorgcoördinatie / PZP
  • Laag 3: Regio-filterpanel — zoom in op één of meerdere regio's
Aanvulling
  • Zodra datum-kolom toegevoegd: trendlijn per maand
  • Exporteerbaar als PDF-rapport voor stuurgroep
Technische opties
  • Power BI, Tableau, of Grafana
Meerwaarde

Stuurt op beweging — ideaal als vaste slide in een maandelijkse stuurgroeprapportage.

Platform-ecosysteem Netwerk-visualisatie

Aanbevolen voor: strategische platform-analyse

Sankey-diagram of netwerk-grafiek die de relatie toont tussen dataplatforms en regio's. Lijndikte = aantal use cases per platform (PZP / Zorgcoördinatie / 360-beeld).

Wat je ziet
  • Welke platforms dominant zijn en waar samenwerking mogelijk is
  • Welke regio's hetzelfde platform gebruiken (schaalvoordeel)
  • Waar overlap of fragmentatie ontstaat
Filtermogelijkheden
  • Per zorgverzekeraar
  • Per use case (PZP / Zorgcoörd / 360-viewer)
Technische opties
  • D3.js (Sankey plugin)
  • Plotly Dash (Python)
  • Power BI Sankey custom visual
Meerwaarde

Strategisch inzicht — welke platforms winnen terrein, waar zijn schaalkansen?

Voorbeeld — Sankey: Platforms → Regio's (per use case)

5

Collaboratief Live Data-portaal

Aanbevolen voor: structurele & duurzame oplossing

Combineer data-invoer en monitoring in één portaal. Elke regio-eigenaar logt in en ziet alleen zijn eigen regio. Het dashboard updatet direct na opslaan.

Werkwijze
  • Pre-ingevuld formulier op basis van wat al bekend is
  • Invuller vult alleen lege velden aan (±10 min per regio)
  • Automatische herinnering bij ontbrekende of verouderde data
  • Versiebeheer en auditlog ingebakken
Technische opties
  • Microsoft Power Apps (form) + SharePoint/Dataverse (backend)
  • Embedded Power BI dashboard (live)
  • Volledig binnen Microsoft 365 — geen nieuwe tooling nodig
Meerwaarde

Lost het datakwaliteitsprobleem structureel op. Geen handmatige Excel-rondes meer nodig. Regio's zijn eigenaar van hun eigen data.
